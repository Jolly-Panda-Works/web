# راهنمای راه‌اندازی (فارسی)

سایت روی **Vercel** منتشر می‌شود. راهنمای کامل مراحل اتصال، متغیرهای محیطی، دامنه و عیب‌یابی ایمیل در [`VERCEL.fa.md`](VERCEL.fa.md) است. این فایل خلاصه‌ای از بقیه تنظیمات است.

## نرخ دلار (نوسان)
در GitHub: **Settings ← Secrets and variables ← Actions** یک secret با نام `NAVASAN_API_KEY` بسازید.

اختیاری (بخش *Variables*):
- `NAVASAN_ITEM` — نوع نرخ؛ پیش‌فرض `usd_sell`. نمونه‌های دیگر: `usd_buy`، `harat_naghdi_sell`، `mex_usd_sell`
- `NAVASAN_UNIT` — پیش‌فرض `toman`: نوسان دلار را به **تومان** می‌دهد (مثلاً ۲۶۸٬۸۰۰) و سایت آن را ×۱۰ می‌کند تا ریال شود. فقط اگر مطمئن شدید عددی که می‌گیرید ریال است `rial` بگذارید.

زمان‌بندی: هر روز ۰۸:۰۰ تهران؛ اگر خطا داد ۲۰:۰۰ همان روز دوباره. اجرای دستی: **Actions ← Update USD rate ← Run workflow**. اگر هر دو بار خطا بدهد، آخرین نرخ سالم روی سایت می‌ماند.

## قیمت‌ها و تخفیف
در `data/plans.json` قیمت‌ها «قیمت قبل از تخفیف» هستند (مثلاً ۲۴٫۹۹ دلار؛ قیمت‌ها می‌توانند سنت داشته باشند و قیمت بعد از تخفیف تا سنت گرد می‌شود). سایت قیمت قبل از تخفیف را خط‌خورده و قیمت بعد از تخفیف را با برچسب «٪ تخفیف» نشان می‌دهد. در حالت فارسی قیمت‌ها با نرخ روز به ریال تبدیل می‌شوند و زیر آن‌ها فقط تاریخ آخرین بروزرسانی قیمت نوشته می‌شود.

### تخفیف روی همه
مقدار `discountPercent` (بالای فایل) تخفیف همه قیمت‌هاست. برای حذف تخفیف از همه، `0` بگذارید.

### تخفیف روی بعضی‌ها
برای هر مورد خاص، فیلد `discount` را کنار همان مورد اضافه کنید. اولویت از قوی به ضعیف:

| محل فیلد `discount` | اثر |
|---|---|
| داخل یک خانه از جدول (`types[].rows.<پلن>`) | فقط همان نوع سایت و همان پلن |
| داخل یک نوع سایت (`types[]`) | همه پلن‌های آن نوع سایت |
| داخل یک پلن (`plans[]`) | آن پلن در همه نوع‌های سایت |
| `discountPercent` بالای فایل | بقیه |

مقدار `0` یعنی «بدون تخفیف» و روی تخفیف‌های ضعیف‌تر غلبه می‌کند. مثال:

```json
"discountPercent": 10,
"plans": [
  { "id": "economy", "discount": 0, "name": { ... } }
],
"types": [
  {
    "id": "store",
    "discount": 20,
    "rows": {
      "special": { "price": 199.99, "discount": 25, ... }
    }
  }
]
```

در این مثال پلن اکونومی در همه جا بدون تخفیف است، ولی فروشگاهی ۲۰٪ می‌گیرد (اولویت نوع سایت از پلن بیشتر است)، و پلن ویژه فروشگاهی ۲۵٪. بقیه ۱۰٪.

بنر بالای صفحه خودکار تنظیم می‌شود: اگر همه تخفیف یکسان باشند «۱۰٪ تخفیف روی همه پلن‌ها» و اگر فرق داشته باشند «تا ۲۵٪ تخفیف روی پلن‌های منتخب» نوشته می‌شود. اگر هیچ تخفیفی نباشد، بنر و برچسب‌ها نمایش داده نمی‌شوند. دستور `node scripts/check.mjs` عددهای نامعتبر را گزارش می‌کند.

## بروشور قیمت (PDF)
در صفحه پکیج‌ها دو دکمه «بروشور انگلیسی» و «بروشور فارسی» هست که فایل PDF دانلود می‌کنند. طراحی PDF همان قالب PowerPoint شماست (`brochure/JollyPanda_Website_Plans_template.pptx`).
- **ساخت خودکار:** GitHub Action (`update-rate.yml`) با `scripts/make-brochure.py` از روی قالب، دو PDF می‌سازد (کتابخانه python-pptx و LibreOffice) و در پوشه `downloads/` کامیت می‌کند؛ Vercel هم همان کامیت را منتشر می‌کند.
- **چه موقع دوباره ساخته می‌شود:** هر روز بعد از گرفتن نرخ جدید، و هر وقت `data/plans.json` (قیمت، تخفیف، متن)، قالب یا اسکریپت را push کنید. اگر هیچ‌چیز عوض نشده باشد، ساخته نمی‌شود.
- **محتوا:** نسخه فارسی راست‌چین با قیمت به ریال (تا وقتی نرخی نباشد به دلار)، نسخه انگلیسی چپ‌چین با قیمت به دلار؛ قیمت قبل از تخفیف خط‌خورده، قیمت جدید، برچسب تخفیف و تاریخ آخرین بروزرسانی روی هر اسلاید.
- **اجرای دستی:** تب Actions ← Update USD rate & price-list PDFs ← Run workflow.
- **تغییر ظاهر:** قالب را در PowerPoint ویرایش کنید ولی ساختار را نگه دارید: ۹ اسلاید، همان نام شکل‌ها (`Text 0`، `Table 0` و ...) و جدول‌هایی با همان سطر و ستون‌ها.
- **حجم:** هر PDF حدود ۴۰۰ کیلوبایت است و نسخه فارسی با تغییر نرخ هر روز یک نسخه جدید در تاریخچه git می‌سازد (حدود ۱۵۰ مگابایت در سال).
- **تفاوت با PowerPoint:** PDF با LibreOffice ساخته می‌شود و فونت‌ها ممکن است کمی با نمایش خود PowerPoint فرق داشته باشند.

## ایمیل (EmailJS)
مراحل ساخت Service و **یک** Template (مناسب پلن رایگان؛ متن هر سه ایمیل داخل سایت ساخته می‌شود) و ثبت شناسه‌ها در [`VERCEL.fa.md`](VERCEL.fa.md) بخش ۲ و در [`email-templates/README.md`](../email-templates/README.md) آمده است. تا زمانی که شناسه‌ها ثبت نشوند، فرم به‌جای ارسال خودکار برنامه ایمیل بازدیدکننده را باز می‌کند.

## نمونه‌کارها
در `data/projects.json`. هر پروژه یک صفحه اختصاصی دارد (`project-detail.html?id=<شناسه>`). تصویر شاخص را در `image` و تصاویر گالری را در `gallery` بدهید؛ بدون تصویر، یک قاب مرورگر با نام دامنه نمایش داده می‌شود.

## نام برند در متن فارسی
در متن‌های فارسی نام برند همیشه به‌صورت لاتین نوشته می‌شود: «استودیو Jolly Panda». دستور `node scripts/check.mjs` اگر در متن فارسی نوشته فارسی نام برند پیدا کند خطا می‌دهد.
